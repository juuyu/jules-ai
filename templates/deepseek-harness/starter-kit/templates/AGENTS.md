## 仓库结构

```text
src/          应用源码（入口 <src/main.xxx>）
docs/         架构与操作文档
.agents/      AI 协作资产：notes/ 决策日志、skills/ 可复用流程
scripts/      检查与构建脚本
tests/        测试
```

## 命令

```sh
<包管理器> install       # 安装依赖
<包管理器> dev           # 本地开发
<包管理器> test          # 单元测试（优先跑相关文件，见下）
<包管理器> lint          # 静态检查
<包管理器> build         # 构建
```

- 提交前只跑**覆盖本次改动的最小检查**；CI 负责穷尽覆盖，本地不重复已通过的检查。
- 报告结果只写**实际跑过的命令与输出**；没验证的项明确标注，不写「应该没问题」。
- 检查失败先修复，不赌 CI 结果不同；命令因环境（网络/权限/沙箱）失败时，记录命令、报错与平台差异，再决定是否重试。
- 密钥只走环境变量（`.env` 已在 .gitignore）；**永不提交凭据**。

## 约定

- **改动面 = 评审面**：一次提交只携带其声明的行为变化所需的行；不夹带无关重构。
- **新行为走既有扩展点**，不新造并行机制；引入新依赖前确认它真的删掉了自有代码和测试。
- **错误大声失败**：配置/引用缺失在最早可检出处报错，不写静默兜底；空 `catch` 必须写明错误名与原因，`try` 只包一条语句。
- **信任同进程的静态类型边界**：只在外部边界（用户输入、配置、网络、持久化、跨进程消息）做运行时校验。
- **注释只讲本地契约**：前置条件、失败模式、所有权、非显而易见的原因；不复述代码、不写改动历史。
- **测试描述行为**：断言外部可观察状态（输出、文件、事件、副作用），不复述实现细节；行为变更时测试同改。
- **一个事实一个家**：同一规则/理由只在一处写全文，别处链接；文档描述当前状态，历史留在提交记录与决策日志。
- **非平凡决策**（新约定、架构取舍、删能力、有争议的修复）在同一提交里附一条 [Agent Note](.agents/notes/README.md)；机械改动与局部样式调整豁免。
- TODO 标记用 `FIXME`（必须修）/ `TODO`（计划中），不写无主注释。
- 文件尾保留恰好一个换行。

## AI 协作流程

接到任务先读本文件与目标目录的说明，再列方案；非平凡决策先写 [Agent Note](.agents/notes/README.md)，评审遵循 [code-review 技能](.agents/skills/code-review/SKILL.md)，推送前遵循 [pre-push-checks 技能](.agents/skills/pre-push-checks/SKILL.md)。

## 编辑本文件

本文件是 AI 协作指令的唯一真实来源；`CLAUDE.md` 等其它工具入口是指向本文件的符号链接，只编辑本文件。每条规则保持 1~3 行、自包含；细节放进它归属的文档并在此链接。目标体量 ≤ 1500 词，超了先把细节搬家，再考虑压缩。
