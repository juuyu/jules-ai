## 写作规范

1. 三要素：每篇文档开头写明「读者是谁 / 解决什么问题 / 何时需要更新」。
2. 事实来源：所有路径、命名、代码示例必须来自真实代码；写完自检一遍。
3. 结构：优先用表格；让读者一屏内定位到目标信息。
4. 风格：与相邻文档保持一致；术语使用项目统一叫法。
5. 更新：只改与现状不符的部分，不做大规模重排。

## 新增文档流程

1. 在 `docs/` 下创建文件（用上面的三要素开头）。
2. 在本文件「文档索引」表登记一行。
3. 检查根 `GEMINI.md` 的「按需查阅」表是否需要补一行。
