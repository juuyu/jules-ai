# 文档质量检查清单

审计或写完文档后，逐项自查。

## 内容正确性
- [ ] 提到的文件、目录、函数、常量在代码中真实存在
- [ ] 代码示例可直接使用（或注明省略了哪些无关部分）
- [ ] 命令、环境变量与实际一致
- [ ] 表格中的编号 / 名称与源码一致（如错误码）

## 结构完整性
- [ ] 开头有「读者 / 用途 / 更新触发条件」三要素
- [ ] 能在 30 秒内定位到目标信息（善用表格与小标题）
- [ ] 该文档已在 `docs/README.md` 索引中登记

## 一致性
- [ ] 术语与项目统一叫法一致（不强造新词）
- [ ] 风格与相邻文档一致（标题层级、表格格式）
- [ ] 与 `GEMINI.md`「按需查阅」索引不矛盾

## 可维护性
- [ ] 不复制易变信息（如完整配置清单），改为指向单一来源
- [ ] 不确定的事实已标注「待确认」而非写成肯定句
