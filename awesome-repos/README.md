## 维护约定

- Star 数标注获取日期；过期后用 `gh api repos/OWNER/REPO --jq '.stargazers_count'` 批量刷新
- 收录标准："当前活跃 + 值得学"；已归档 / 停更的项目显式标注而非直接删除（了解生态演变同样有价值）
- 品类变化快（收购、更名、停运频繁），新增条目时顺带核对旧条目状态
- 仓库迁移 / 更名记录在各文件备注中（GitHub 会自动重定向旧地址）
